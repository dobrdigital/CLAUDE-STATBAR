# CLAUDE-STATBAR — инструкция для агентов

Статус-строка (statusline) для Claude Code, работающего через OpenRouter. Показывает реальные данные из API: баланс ключа, расход за день, цену модели за 1M токенов (вход • выход, со скидкой провайдера), токены сессии, кэш и реальный лимит контекста.

## Структура файлов

| Файл | Назначение |
|---|---|
| `statusline-command.sh` | сам скрипт: bash-обёртка + встроенный python. Читает JSON-пайлоад из stdin, печатает одну строку |
| `test-statusline.sh` | автотест: 16 проверок, офлайн, детерминированный (засеивает временный HOME) |
| `README.md` | пользовательская документация (RU) |
| `settings.example.json` | шаблон конфига — **только плейсхолдер ключа** |
| `example-payload.json` | пример пайлоада для ручного запуска |
| `hooks/pre-commit` | блокирует коммит с реальным ключом |
| `.gitignore` | исключает `settings.json`, `settings.local.json`, `cache/` |

## Команды

```bash
# тест (без сети)
bash test-statusline.sh

# ручной запуск
bash statusline-command.sh < example-payload.json

# установка на машину пользователя (см. README):
# конфиг в ~/.claude/settings.json (env + statusLine) + копия скрипта
```

## Правила для агентов (обязательно)

1. **НИКОГДА** не клади реальный ключ `sk-or-v1-...` в файлы. Только плейсхолдер `sk-or-v1-ТВОЙ_КЛЮЧ` или env `ANTHROPIC_AUTH_TOKEN`.
2. Guard-хук `~/.claude/hooks/scan-keys.sh` сканит каждый записанный/изменённый файл. Если он сработал — не коммить файл, убери ключ.
3. Живой скрипт статус-строки: `~/.claude/statusline-command.sh`. При правке — синхронизируй обе копии (`cp ~/.claude/statusline-command.sh statusline-command.sh`) и прогони тест. Если менял только репозиторную копию — наоборот.
4. Windows-Python пишет stdout в cp1252 — не-ASCII разделители (`•`) ломаются. Выход обязателен через `sys.stdout.reconfigure(encoding="utf-8")` (уже есть в скрипте).
5. Цены: `/api/v1/models` отдаёт базовый прайс; **реальная цена со скидкой** — из `/api/v1/models/{id}/endpoints` (самый дешёвый эндпоинт). Контекст — из `top_provider.context_length`.
6. Процент контекста пересчитывать от реального лимита (`100·in/limit`), НЕ верить `used_percentage` из пайлоада (Claude Code считает от своего ложного лимита ~200k).
7. Статус-строка перерисовывается только на новые события/сессию — сообщение после правки обязательно.
